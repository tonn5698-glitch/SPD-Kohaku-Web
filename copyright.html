1. About this page

SPD-Kohaku is a fan-made mod built on top of Shattered Pixel Dungeon. It features the custom character Kohaku as the only playable hero, with a 4-direction sprite system and RPG Maker-style dialog. This page exists to keep attribution clear: what belongs to whom, under what license, and what permission status each piece has.

If you are a rights holder and believe something here is used incorrectly, see Contact below.

4. Original Characters

The following hero classes are from the original Shattered Pixel Dungeon and are not playable in this mod (locked):

  • Warrior — Berserker / Gladiator subclasses
  • Mage — Battlemage / Warlock subclasses
  • Rogue — Assassin / Freerunner subclasses
  • Huntress — Sniper / Warden subclasses
  • Cleric — Priest / Paladin subclasses

Only the Duelist (replaced by Kohaku) is playable.
